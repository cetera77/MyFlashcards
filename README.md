# MyFlashcards

Anki / AnkiDroid を参考にした、iPad 向けのシンプルな間隔反復フラッシュカードアプリです。HTML・CSS・JavaScript のみで作られており、外部ライブラリやビルド作業は不要です。PWA（ホーム画面に追加して使うウェブアプリ）として動作し、学習データは端末内にのみ保存されます。

旧名は MyAnki です。

## 主な機能

- デッキの作成・名前変更・削除
- 基本カード（表面・裏面）と穴埋め（クローズ）カード
- カードの追加・編集・削除・検索
- SM-2 系アルゴリズムによる間隔反復学習（Anki の従来スケジューラーの初期設定に準拠、ファズと期限超過の反映を含む）
- 4 段階評価（もう一度 / 難しい / 正解 / 簡単）と、各ボタンへの次回間隔の表示
- デッキごとの 1 日の新規カード数・復習上限の設定
- 学習統計（今日の成績、カードの内訳、今後の復習予定、学習履歴、正答率）
- 直前の回答の取り消し（1 回分）
- テキスト読み上げ
- TSV / CSV / セミコロン区切りテキストのインポート（Anki の「ノートをプレーンテキストで書き出し」にも対応）
- 全データの JSON バックアップと復元、バックアップの催促
- ダークモード（端末設定に追従）
- 外付けキーボード操作
- オフライン動作（Service Worker によるキャッシュ）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML・CSS・JavaScript をすべて含む） |
| `manifest.json` | PWA のマニフェスト |
| `sw.js` | オフライン用の Service Worker |
| `apple-touch-icon.png` | ホーム画面用アイコン（180×180） |
| `icon-192.png` | マニフェスト用アイコン（192×192） |
| `icon-512.png` | マニフェスト用アイコン（512×512） |


## 導入方法

iPadOS の Safari では、「ファイル」アプリ内の HTML を直接開いてアプリとして使うことはできないため、静的ホスティングで公開してから iPad に追加します。公開されるのはアプリ本体のみで、学習データはサーバーに送信されません。


## 使い方

1. デッキ一覧でデッキ名を入力して「追加」
2. デッキを開き「カード追加」または「インポート」でカードを登録
3. 「学習開始」で学習
4. カードまたは「答えを表示」をタップし、4 つの評価ボタンのいずれかを選ぶ

デッキ一覧の数字は、左から新規（青）・学習中（赤）・復習（緑）の本日の残り枚数です。学習中には、20 分以内に出題されるカードも含まれます。学習画面では、表示中のカードが属する種類の数字に下線が付きます。

### 穴埋めカード

カード追加画面で「ノートの種類」を「穴埋め」にし、テキストの隠したい部分を選択して「穴埋め（新しい番号）」を押します。直接 `{{c1::答え}}` と入力することもできます。

- `{{c1::答え::ヒント}}` とすると、問題に「[ヒント]」と表示されます
- 番号ごとに 1 枚のカードが作られます
- 同じ番号の部分は、同じカードで一緒に隠されます（「穴埋め（同じ番号）」ボタン）
- 「追加情報」に入力した内容は、答えの下に表示されます
- 編集するとそのノートのカードすべてに反映されます。番号を消すと、その番号のカードは削除されます
- カード一覧で削除すると、同じノートのカードがすべて削除されます
- 作成後にノートの種類（基本 / 穴埋め）を変えることはできません

### 統計

デッキ一覧の「全体の統計」、またはデッキ画面の「統計」で表示します。グラフの棒をタップすると、その日の詳細が表示されます。

- 今日：回答数、学習時間、種類別の内訳、復習カードの正答率
- カードの内訳：新規・学習中・若い（間隔 21 日未満）・成熟（21 日以上）の枚数
- 今後の復習予定：日ごとの予定枚数
- 学習履歴：日ごとの回答数、連続学習日数
- 正答率：復習カードで「もう一度」以外を押した割合

学習履歴と正答率は、バージョン 1.3 以降の回答から記録されます。

### キーボード操作

学習画面:

| キー | 動作 |
| --- | --- |
| Space / Enter | 答えを表示。表示後は「正解」 |
| 1 / 2 / 3 / 4 | もう一度 / 難しい / 正解 / 簡単 |
| Cmd + Z / Ctrl + Z | 元に戻す |

穴埋めのテキスト入力中:

| キー | 動作 |
| --- | --- |
| Cmd + Shift + C / Ctrl + Shift + C | 穴埋め（新しい番号） |
| 上記 + Option / Alt | 穴埋め（同じ番号） |

## インポート形式

- 1 行につき 1 件。1 列目が表面（穴埋めではテキスト）、2 列目が裏面（穴埋めでは追加情報）。3 列目以降は無視
- 区切り文字はタブ・カンマ・セミコロンから選択（拡張子が .csv のファイルは自動でカンマを選択）
- ノートの種類は、自動判定（`{{c1::…}}` を含む行は穴埋め）・基本・穴埋めから選択
- ダブルクォートで囲んだフィールド内の改行・区切り文字に対応
- # で始まる行は無視（Anki の書き出しファイルのヘッダー行を想定）
- 同じデッキ内で表面が完全一致するものはスキップ可能

Anki から書き出したデータに HTML が含まれる場合は、設定で「カード内の HTML を解釈する」をオンにしてください。

## バックアップ

設定画面の「全データを書き出し（JSON）」で、全デッキ・全カード・学習状況・学習履歴を 1 つのファイルに保存できます。共有シートから「"ファイル"に保存」を選んでください。復元すると現在のデータは置き換えられます。MyAnki 時代のバックアップファイルも復元できます。

最後の書き出しから 7 日以上経過すると、デッキ一覧にお知らせが表示されます。一度も書き出していない場合は、学習したカードが 1 枚でもあれば表示されます。

## 注意事項

- Safari で開いた場合とホーム画面から起動した場合では、保存領域が別になります。必ずホーム画面のアイコンから使ってください。
- アプリをホーム画面から削除する、または Safari の Web サイトデータを消去すると、学習データも消えます。定期的にバックアップしてください。
- 保存先は localStorage のため、容量は数 MB 程度です。学習履歴も同じ領域に保存されます。
- Anki の .apkg ファイル、画像・音声の添付、Anki / AnkiWeb との同期には対応していません。
