# MyFlashcards

AnkiDroid / Anki を参考にした、iPad 向けのシンプルな間隔反復フラッシュカードアプリです。HTML・CSS・JavaScript のみで作られており、外部ライブラリやビルド作業は不要です。PWA（ホーム画面に追加して使うウェブアプリ）として動作し、学習データは端末内にのみ保存されます。

## 主な機能

- デッキの作成・名前変更・削除
- カードの追加・編集・削除・検索
- SM-2 系アルゴリズムによる間隔反復学習（Anki の従来スケジューラーの初期設定に準拠）
- 4 段階評価（もう一度 / 難しい / 正解 / 簡単）と、各ボタンへの次回間隔の表示
- デッキごとの 1 日の新規カード数・復習上限の設定
- 直前の回答の取り消し（1 回分）
- テキスト読み上げ
- TSV / CSV / セミコロン区切りテキストのインポート（Anki の「ノートをプレーンテキストで書き出し」にも対応）
- 全データの JSON バックアップと復元
- ダークモード（端末設定に追従）
- 外付けキーボード操作
- オフライン動作（Service Worker によるキャッシュ）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML・CSS・JavaScript をすべて含む） |
| `manifest.json` | PWA のマニフェスト |
| `sw.js` | オフライン用の Service Worker |

3 つのファイルは同じフォルダに置いてください。

## 導入方法

iPadOS の Safari では、「ファイル」アプリ内の HTML を直接開いてアプリとして使うことはできないため、静的ホスティングで公開してから iPad に追加します。公開されるのはアプリ本体のみで、学習データはサーバーに送信されません。

### GitHub Pages を使う場合

1. GitHub で公開リポジトリを作成する
2. 3 つのファイルをリポジトリのルートにアップロードする
3. リポジトリの Settings → Pages で「Deploy from a branch」を選び、main ブランチを指定して保存する
4. 表示された URL（https://ユーザー名.github.io/リポジトリ名/）を iPad の Safari で開く
5. 共有ボタン →「ホーム画面に追加」を選ぶ
6. ホーム画面のアイコンから一度起動する（以後はオフラインでも動作する）

### Netlify Drop を使う場合

3 つのファイルを入れたフォルダを Netlify Drop の画面にドラッグ＆ドロップし、発行された URL で上記 4〜6 を行います。

## 使い方

1. デッキ一覧でデッキ名を入力して「追加」
2. デッキを開き「カード追加」または「インポート」でカードを登録
3. 「学習開始」で学習
4. カードまたは「答えを表示」をタップし、4 つの評価ボタンのいずれかを選ぶ

デッキ一覧の数字は、左から新規（青）・学習中（赤）・復習（緑）の本日の残り枚数です。

### キーボード操作（学習画面）

| キー | 動作 |
| --- | --- |
| Space / Enter | 答えを表示。表示後は「正解」 |
| 1 / 2 / 3 / 4 | もう一度 / 難しい / 正解 / 簡単 |
| Cmd + Z / Ctrl + Z | 元に戻す |

## インポート形式

- 1 行につき 1 枚。1 列目が表面、2 列目が裏面（3 列目以降は無視）
- 区切り文字はタブ・カンマ・セミコロンから選択（拡張子が .csv のファイルは自動でカンマを選択）
- ダブルクォートで囲んだフィールド内の改行・区切り文字に対応
- # で始まる行は無視（Anki の書き出しファイルのヘッダー行を想定）
- 同じデッキ内で表面が完全一致するカードはスキップ可能

Anki から書き出したデータに HTML が含まれる場合は、設定で「カード内の HTML を解釈する」をオンにしてください。

## バックアップ

設定画面の「全データを書き出し（JSON）」で、全デッキ・全カード・学習履歴を 1 つのファイルに保存できます。共有シートから「"ファイル"に保存」を選んでください。復元すると現在のデータは置き換えられます。

## 注意事項

- Safari で開いた場合とホーム画面から起動した場合では、保存領域が別になります。必ずホーム画面のアイコンから使ってください。
- アプリをホーム画面から削除する、または Safari の Web サイトデータを消去すると、学習データも消えます。定期的にバックアップしてください。
- 保存先は localStorage のため、容量は数 MB 程度です。テキスト中心で数千〜1 万枚程度が目安です。
- Anki の .apkg ファイル、画像・音声の添付、Anki / AnkiWeb との同期には対応していません。

## 更新方法

ファイルを差し替えたあと、オンライン状態でアプリを開き直すと新しい版が読み込まれます。反映されない場合は `sw.js` の `CACHE` の値（例: `myanki-v1`）を変更してください。
